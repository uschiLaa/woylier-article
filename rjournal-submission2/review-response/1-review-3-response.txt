## Referee report of "Frame to frame interpolation for high-dimensional data visualisation using the woylier package".

- **Id**: 2023-131

## General

The article describes a method to rotate points within the plane while conducting a tour, in order to maximize the spline index value which can be used to guide projection pursuit tours. This is an improvement on previous methods, and provides useful functionality to the R community. The paper is well written, though it could probably address other obvious and straightforward solutions to the defined problem, such as modifying the calculation of the spline index so that it is rotation invariant (e.g. by maximizing over rotation angle theta).

## Code

Usability:

- It is often helpful to have a short example on the main page of the package documentation. Right now, https://numbats.github.io/woylier/ just has the install_github() command. Presumably that should be updated to include the CRAN release as well?
- The getting started page of the documentation on the website could include a few gifs of the resulting tours with and without the rotation features added by woylier. This might provide some motivation (and intuition) for someone investigating the package to see how the rotation method works -- most people won't benefit that much from the printing of matrix slices.
- It would be nice to see longer descriptions/motivations for some of the package functions that include some of the content in the paper (e.g. the math notation underlying how the functions work), rather than the one sentence descriptions that are currently present.
- The plots in the vignette should be optimized for accessibility and color contrast, and if possible, it would be nice to not have the points overlap the projection indicator in the bottom left corner. https://numbats.github.io/woylier/articles/Plotting_with_woylier.html

Code:

- The package code could be modularized a bit more effectively, using shorter functions that only accomplish one task. This is admittedly a stylistic choice, but there are a few functions that are a bit too long for my personal comfort.
- I'm not sure why this is a separate package instead of being integrated into a new release of tourr directly. The number of additional functions is small and the package relies so heavily on tourr that it would seem to be easier just to combine the packages given the number of common authors. While there are obviously advantages in terms of additional publications and CV line items, I'm not convinced it's advantageous to the R user to have to install e.g. 5 packages to get the full tour functionality.
